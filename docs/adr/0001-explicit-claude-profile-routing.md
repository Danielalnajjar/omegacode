# Port per-agent subscription routing from BB workflows to Omega

BB workflows already let concurrent agents in the same stage use different named Claude subscriptions through per-agent ACP provider routes. OmegaCode will provide the same user-facing capability through its direct Claude worker: Subscription Picker exposes each resolvable Fixed Claude Profile, and an Omega agent selects it with `provider: 'claude-code'` plus `claudeProfile`, never with a BB `acp-sub-*` provider id. Profiles change only the endpoint for new work and remain outside cache identity; unrelated accounts and providers, existing workflows, BB routes, and child threads are unchanged. No existing workflow is converted. Completion requires source tests plus a dedicated smoke workflow proving simultaneous agents on different subscriptions in one stage and simultaneous agents sharing one subscription, without traversing BB ACP. Automatic Profile Pool selection remains a separate possible future capability.
